# מעורר משימה – שעון מעורר מבוסס משימות פיזיות

אפליקציית אנדרואיד נייטיב (Kotlin + Jetpack Compose) של שעון מעורר "קשוח":
השעון לא נכבה עד ש**קמים מהמיטה ומצלמים מקום בבית** – את המקרר, את מתג האור, את כיור האמבטיה…

**איך זה עובד**
1. **רישום חד-פעמי** (מסך "המקומות שלי"): מצלמים כל מקום פעמיים מזוויות קצת שונות. מתוך 30 מקומות שיש כמעט בכל בית (מטבח, אמבטיה, סלון, כניסה, מתג תאורה, מרפסת…).
2. **בבוקר**: מוגרלת משימה – מקום אחד (קל), שני מקומות באותו חדר (בינוני), או שני מקומות בחדרים שונים (קשה). המצלמה החיה מושווית כל הזמן לתמונה ששמרת, והשעון נכבה כשיש התאמה בשני פריימים ברצף.
3. **ספרייה**: 30 מקומות → **465 משימות צילום** (`data/PhotoCatalog.kt`). זמינות רק משימות שכל המקומות שלהן צולמו.

**איך מאמתים שזה אותו מקום** (`data/ImageFeatures.kt`, הכול על המכשיר):
* תוויות של ML Kit Image Labeling (מודל מובנה, בלי אינטרנט) – דמיון קוסינוס.
* היסטוגרמות צבע של כל התמונה ושל 4 הרבעים שלה (צבע + מבנה) – חיתוך היסטוגרמות.
* סף לכל מקום נקבע לפי הדמיון בין שתי תמונות הרישום, כך שמקומות "קשים" מקבלים סף מותאם.

במסך ההגדרה יש כפתור "נסה את המשימה עכשיו" לתרגול לפני הדריכה.

> ⚠️ ספי ההתאמה הם הערכה התחלתית וצריך לכייל אותם בבדיקות על טלפונים אמיתיים (תאורה שונה, זוויות שונות). אם הזיהוי לא מצליח: החלפת משימה עד 3 פעמים ואז משימת חירום (אור + 150 צעדים), כך שתמיד אפשר לכבות – אבל רק אחרי שקמים.
גם **כיבוי, עריכה או מחיקה של שעון דרוך** דורשים לבצע את המשימה באותו רגע, כך שאי אפשר "לבטל מראש" בערב.

## יכולות

| תחום | מימוש |
|---|---|
| תזמון אמין | `AlarmManager.setAlarmClock()` – מדויק, פטור מ-Doze, מציג אייקון שעון בשורת המצב |
| צלצול ברקע / מסך נעול | `AlarmService` – Foreground Service מסוג `mediaPlayback` עם wake lock |
| הקפצת מסך | ערוץ התראות `IMPORTANCE_HIGH` + Full-screen intent ל-`AlarmActivity` (`showWhenLocked`, `turnScreenOn`) |
| משימות צילום | CameraX (ImageAnalysis, ‏~2 פריימים בשנייה) + ML Kit Image Labeling (מודל מובנה), כולל פנס |
| משימת חירום | אור (`TYPE_LIGHT`, עלייה פי 3) ואז 150 צעדים (`TYPE_STEP_DETECTOR` / חיישן תאוצה) |
| שמירת נתונים | Room (SQLite) – שעונים ומקומות רשומים – ב-Device-Protected Storage – השעונים נדרכים מחדש ומצלצלים גם אחרי אתחול לפני פתיחת הנעילה |
| הישרדות | דריכה מחדש אחרי אתחול, עדכון אפליקציה, שינוי שעה/אזור זמן ושינוי הרשאת שעונים מדויקים |
| צלילים | 3 צלילים מובנים שמסונתזים בקוד, צליל המערכת, צלצולי המכשיר, או **כל קובץ שמע מהטלפון** (mp3 וכו', הרשאת קריאה קבועה). הצליל האחרון שנבחר הופך לברירת המחדל לשעונים חדשים |
| עיצוב | Material 3, עברית מלאה, RTL כפוי, ערכות כהה/בהירה, Edge-to-edge |

### מנגנון ההגנה (Anti-Cheat)
* שעון **דרוך** (מתג פעיל) מסומן במנעול. כיבוי המתג, לחיצה לעריכה או מחיקה מעבירים ל"מסך אתגר" – הפעולה מתבצעת רק אחרי השלמת המשימה (כלומר אחרי שקמת).
* דריכה של שעון כבוי – חופשית.
* בזמן צלצול: כפתור Back חסום, כפתורי עוצמה "נבלעים" במסך האזעקה, ועוצמת ערוץ ה-Alarm ננעלת (מוחזרת אוטומטית כל 1.5 שניות אם הורידו אותה).
* אין כפתור "כבה" או "נודניק" בהתראה. אם ההתראה מוחלקת (אפשרי באנדרואיד 14+) היא מוצגת מחדש. פתיחת האפליקציה בזמן צלצול מחזירה למסך האזעקה.
* מגבלה: אפשר תיאורטית לרמות עם תמונה של המקום על מסך אחר. בפועל זה דורש להכין את זה מראש.
* אם התהליך נהרג בזמן צלצול, השירות חוזר לצלצל (`START_REDELIVER_INTENT`).
* **משימת חירום**: אחרי 3 החלפות משימה (או כשלא צולם אף מקום) – אור ו־150 צעדים. עדיין צריך לקום. זה מונע מצב שבו השעון לא ניתן לכיבוי לעולם – חשוב גם לבטיחות וגם לעמידה במדיניות Google Play.

### מגבלות שחשוב לדעת
אנדרואיד לא מאפשר לאפליקציה רגילה (ובטח לא אפליקציה ב-Google Play) למנוע הסרה, "עצירה בכוח" (Force stop) או כיבוי של המכשיר. Force stop מבטל את השעונים שנקבעו עד שהאפליקציה נפתחת שוב. ההגנה היא על כל מה שקורה **בתוך** האפליקציה.

## מבנה הקוד

```
app/src/main/java/com/taskalarm/app/
├── TaskAlarmApp.kt              # Application – יצירת ערוצי התראות
├── data/                        # Room: Alarm, AlarmDao, AppDatabase (+migration), AlarmRepository, NextAlarmCalculator, Days, PhotoCatalog, ImageFeatures, Place
├── alarm/                       # AlarmScheduler, AlarmReceiver, BootReceiver, AlarmService,
│                                # NotificationHelper, AlarmSoundPlayer, SoundLibrary, ToneSynth
└── ui/
    ├── MainActivity.kt          # Navigation: permissions → dashboard → edit / challenge
    ├── dashboard/               # מסך הבית – שעון גדול, רשימת שעונים, FAB
    ├── edit/                    # הגדרת שעון + MissionPicker (ספריית משימות הצילום)
    ├── challenge/               # מסך האתגר לפעולות על שעון דרוך
    ├── ringing/                 # AlarmActivity + RingingScreen + "בוקר טוב!"
    ├── task/                    # PhotoCamera, PhotoTask, EmergencyTask, StepsTask, TaskChallenge
    ├── places/                  # רישום המקומות בבית (צילום פעמיים לכל מקום)
    ├── permissions/             # מסך הרשאות עם הסברים + PermissionUtils
    └── theme/
```

## בנייה

דרישות: Android Studio (Narwhal ומעלה) או JDK 17 + Android SDK 36.

```bash
./gradlew testDebugUnitTest      # בדיקות יחידה
./gradlew assembleDebug          # APK לבדיקה: app/build/outputs/apk/debug/
./gradlew bundleRelease          # AAB להעלאה ל-Google Play
```

ה-workflow ב-`.github/workflows/android.yml` מריץ בדיקות, בונה APK ו-AAB ומריץ lint על כל push.

### חתימה לשחרור
צור מפתח העלאה ושמור `keystore.properties` בשורש הפרויקט (מוחרג מ-git):

```properties
storeFile=/absolute/path/upload-keystore.jks
storePassword=********
keyAlias=upload
keyPassword=********
```

```bash
keytool -genkeypair -v -keystore upload-keystore.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload
```

מומלץ להפעיל Play App Signing ב-Play Console.

## בדיקה ידנית מומלצת
1. צלם לפחות מקום אחד ב"המקומות שלי", צור שעון לעוד 2 דקות, נעל את המסך וחכה – המסך צריך להידלק ולהציג את האזעקה.
2. נסה Back, כפתורי עוצמה, החלקת ההתראה ופתיחת האפליקציה – האזעקה ממשיכה.
3. צלם מקום אחר – אין התאמה. צלם את המקום הנכון – "בוקר טוב!".
4. צלם 3–4 מקומות, ובדוק בבוקר שהזיהוי מצליח באותו מקום ונכשל במקום אחר. נסה "החלף משימה".
5. נסה לכבות/למחוק/לערוך שעון דרוך – נדרש אתגר.
6. אתחל את המכשיר בלי לפתוח נעילה – השעון עדיין מצלצל בזמן.
